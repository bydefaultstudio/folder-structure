About Folder Structure

Folder Structure is a free tool for visualising folder structures. Paste a structure in any common format, whether that is a tree diagram, an indented list, markdown bullets or file paths, and it becomes an interactive diagram. Click a folder to open or close it, drag the canvas to move around, and switch on Edit to add, rename, reorder and delete items. When you are happy, export your structure as clean tree text, ready to paste into Claude or any other AI tool.
